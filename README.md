# Ontol Access Control 배포

병원 원내망 브로커 PC용 TCP 접근제어 프로그램 Ontol Access Control의 설치 파일을 배포하는 저장소입니다. 소스 코드는 이 저장소에 없습니다.

- 설치 파일: [최신 릴리스](https://github.com/Tesser/ontol-access-control-releases/releases/latest)
- 설치된 앱(1.4.0 이상)은 이 저장소 최신 릴리스의 `latest.json`을 확인해 새 버전을 알립니다. `latest.json`은 앱에 내장된 공개키로 서명을 검증한 경우에만 사용합니다.
- 파일 무결성은 각 릴리스의 `SHA256SUMS-<버전>.txt`로 확인할 수 있습니다.

문의: Tesser
